# 리듬 알고리즘

1. 제목을 Unicode 호환 정규화하고 날짜·예약·방문 같은 일반 토큰을 제거한다.
2. 정규화 토큰의 blocking key로 비교 범위를 줄인 뒤 유사도 임계값 이상을 묶는다.
3. 최소 3회의 날짜를 일 단위로 중복 제거한다.
4. 인접 간격의 중앙값과 MAD를 계산하고 `max(3σ, 중앙값×0.35, 3일)` 밖의 간격을 이상치로 제외한다.
5. 가중 중앙값을 기본 주기로, MAD와 IQR을 예상 기간 폭으로 사용한다.
6. 표본 수, 변동성, 제목 유사도, 최근성, 사용자 확인을 조합해 신뢰도를 계산한다.

예측은 단일 날짜가 아니라 시작·중심·종료의 `DateWindow`로 표현한다. 완료 기록은 다음 기준일이 되고, 미루기는 창 전체를 7일 이동하며, 건너뛰기는 기본 주기만큼 이동한다.
