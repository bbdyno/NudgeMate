# App Store 개인정보 답변 초안

실제 제출 빌드와 운영 정책을 다시 대조한 뒤 입력한다.

## 데이터 수집

현재 구현은 개발자 또는 제3자 서버로 사용자 데이터를 전송하지 않으므로 App Store Connect의 “데이터 수집”에는 수집하지 않음을 선택한다. 캘린더 이벤트와 사용자 입력은 기능 제공 목적으로 기기에서만 처리한다.

## 추적

ATT, 광고 식별자, 제3자 광고 SDK, 교차 앱 추적을 사용하지 않으므로 추적하지 않음을 선택한다.

## 시스템 권한

캘린더 전체 접근은 반복 일정 분석과 사용자가 요청한 일정 저장에 사용한다. 알림 권한은 리듬, 준비 체크인, Daily Recap에 사용한다. 결제 거래는 StoreKit 2가 처리하며 앱은 결제 수단 정보를 수집하지 않는다.
