# 알림 구조

| 구분 | 시점 | 액션 | 결과 |
|---|---|---|---|
| 리듬 | 예상 시작 D-3 | 일정 잡기 | 앱을 열어 EventKit 저장 |
| 리듬 | 예상 시작 D-3 | 1주 미루기 | 예상 기간 전체 +7일 |
| 리듬 | 예상 시작 D-3 | 이번만 건너뛰기 | 다음 주기로 이동 |
| 준비 | 계산된 체크인 | 준비 전 | 다음 체크인 재계산 |
| 준비 | 계산된 체크인 | 진행 중 | 다음 체크인 재계산 |
| 준비 | 계산된 체크인 | 준비 완료 | 이후 알림 취소 |
| Daily Recap | 설정된 저녁 시간 | 열기 | Recap 시트 표시 |

식별자는 `rhythm.<UUID>`, `prep.<UUID>`, `recap.<offset>` 형식이다. 같은 식별자는 제거 후 다시 등록해 중복을 방지한다. 앱이 종료된 상태의 액션은 `NotificationActionRouter`가 SwiftData를 갱신하며, 실패하면 pending intent로 보존한다. 일반 개인정보 모드에서는 일정 이름을 알림에 표시하지 않는다.
