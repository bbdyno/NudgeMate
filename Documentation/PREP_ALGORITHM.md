# 준비 체크인 알고리즘

남은 일수 `R`을 기준으로 준비 전은 `R×0.2`, 진행 중은 `R×0.4`를 기본 간격으로 삼는다. 높은 빈도는 0.75배, 낮은 빈도는 1.25배를 적용하고 남은 기간 구간별 상한을 둔다.

- 준비 전: 최소 1일, 최대 4일
- 진행 중: 최소 2일, 최대 7일
- 목표일까지 2일 이하: 다음 날 최종 확인
- 준비 완료: 예약 알림 취소
- 목표일 경과: `targetPassed`로 전환
- 무응답 재시도: 1회까지만 허용

계산은 `Calendar.startOfDay`를 사용해 DST와 시간대 변경에 안전하게 동작한다.
