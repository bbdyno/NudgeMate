# 제품 명세

## 목표

사용자가 반복 일정을 뒤늦게 떠올리는 문제와 중요한 일정의 준비를 한 번의 알림에 의존하는 문제를 해결한다.

## 핵심 흐름

1. 가치와 개인정보 처리 방식을 설명한 뒤 사용자가 캘린더 접근을 선택한다.
2. 선택한 캘린더의 최근 12개월 일정에서 반복 후보를 찾는다.
3. 사용자가 후보의 이름과 분류를 확인한 경우에만 리듬으로 저장한다.
4. 예상 기간 시작 3일 전에 알리고 일정 추가, 1주 미루기, 이번만 건너뛰기를 제공한다.
5. 중요 일정은 준비 전·진행 중·완료 응답에 따라 다음 체크인을 계산한다.
6. 홈 화면·잠금 화면 위젯은 가장 가까운 준비를 표시하고 해당 준비로 바로 이동한다.
7. 사용자가 준비를 `진행 중`으로 바꾸면 Live Activity가 시작되고 완료·취소·삭제 시 종료된다.

## 요금제

무료는 수동 고정 리듬 무제한, 활성 적응형 리듬 3개, 활성 준비 1개를 제공한다. Pro는 적응형 리듬과 준비 한도를 해제한다. Google Calendar와 외부 백엔드는 현재 범위에 포함하지 않는다.

위젯과 Live Activity는 모든 요금제에서 제공한다. Pro 여부가 잠금 화면의 핵심 준비 정보 접근성을 제한하지 않는다.
