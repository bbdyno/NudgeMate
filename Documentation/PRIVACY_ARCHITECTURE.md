# 개인정보 보호 구조

- 캘린더 분석은 EventKit과 앱 프로세스 안에서 수행한다.
- Google API, 광고 SDK, 분석 SDK, 외부 백엔드를 사용하지 않는다.
- 전체 캘린더 원문을 SwiftData에 복제하지 않는다.
- 로그에 일정 제목, 위치, 참석자를 남기지 않는다.
- 잠금 화면 알림은 상세 또는 일반 문구를 사용자가 선택한다.
- 사용자는 JSON 내보내기와 전체 앱 데이터 삭제를 실행할 수 있다.
- 전체 삭제는 로컬 모델과 예약 알림을 제거하지만 App Store 구매 권한은 제거하지 않는다.

배포 전 실제 개인정보처리방침 URL을 `NudgeMatePrivacyPolicyURL` Info.plist 키에 넣어야 한다. URL이 없으면 앱은 작동하지 않는 가짜 링크를 표시하지 않는다.
